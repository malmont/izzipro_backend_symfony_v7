Libellés exacts de l'éditeur (relevés par le frontend le 07/10/2026 ; source : docs/ia-libelles-editeur.md du dépôt Izzipro_next).

CONVENTIONS
- « Panneau » : panneau latéral, ouvert par le bouton « ⚙️ Éditeur » (en bas à droite de la page) ou par « ⚙️ Réglages » dans la barre au-dessus d'une section.
- « Barre de la section » : barre d'outils au-dessus de chaque section sur la page. « Barre du bloc » : barre flottante du bloc sélectionné.
- « Section → » abrège « Panneau → Section N → Éditeur visuel → ».
- Les réglages d'un bloc n'apparaissent qu'une fois le bloc sélectionné (clic sur le bloc, ou dans « 🗂 Calques »).

STRUCTURE DES PAGES ET SECTIONS
- Ajouter une page : Panneau → « ＋ Ajouter un onglet » ; la supprimer : « × » à côté.
- Nom dans le menu : Panneau → « Titre de l'onglet (Français) » / « Titre de l'onglet (Anglais) ».
- Page hors menu : Panneau → décocher « Afficher dans le menu du site ».
- Ajouter une section : Panneau → « ＋ Ajouter une section ». Monter / descendre / supprimer : en-tête « Section N » → « ↑ », « ↓ », « × ».
- Nommer une section : Panneau → Section N → « Nom de la section (facultatif) ». Changer sa famille : « Type de composant ».
- Annuler / rétablir : Section → « ↩ » / « ↪ ». Aperçu : Section → « 👁 Aperçu ».
- Ajouter un bloc : Barre de la section → « Bloc », « Titre », « Texte », « Bouton », « Image », « Badge », « Ligne », « Chiffre », « Vidéo », « ＋ Plus ».
- Ensemble prêt à l'emploi : Barre de la section → « 🧩 Composants ».
- Dupliquer, passer devant / derrière, supprimer un bloc : Barre du bloc.
- Liste des blocs : Section → « 🗂 Calques ». Organisation d'un conteneur : bloc conteneur → « Disposition des enfants ».
- Enregistrer la mise en page : Panneau → « 💾 Sauvegarder ».

STYLE DE LA SECTION
Section → « 📐 Section : dimensions & fond » : « Couleur de fond », « Image de fond (URL) », « Vidéo de fond », « Image de fond fixe au défilement », « Filtre sombre fond (%) », « Voile sur l'image », « Cadrage de l'image », « Hauteur min. (% écran) », « Hauteur min. mobile (%) », « Largeur maximale (px) », « Largeur du contenu (px) », « Marge intérieure (px) », « Espacement (px) », « Disposition de la section », « Ancre de la section ». Navbar seulement : « Barre superposée au début de la page (fond transparent sur un héros) », « Fond après défilement », « Couleur du texte après défilement », « Fond flouté (verre) après défilement ».
Style d'un bloc (sélectionné) :
- Carte « … sélectionné » → « Couleur de fond », « Couleur texte », « Taille texte (px) », « Alignement », « Hauteur (px) », « Couleur bordure ».
- « 🎨 Style avancé » → « Police », « Interligne », « Espacement lettres (em) », « Ombre », « Ombre du texte », « Effet au survol », « Opacité (%) », « Apparition (à l'écran) », « Délai d'apparition (s) », « Durée d'apparition (s) » ; un mot en valeur : « Mot mis en valeur », « Couleur du mot », « Police du mot », « Taille du mot (× texte) ».
- Gras, italique, couleur ou lien sur quelques mots : double-clic sur le texte, sélectionner les mots, barre de mise en forme (B, I, U, S, couleurs, 🔗).
- Pas de police commune au site : elle se règle bloc par bloc (« 🎨 Style avancé » → « Police »).
- Mobile : « 📱 Sur mobile » → « Masquer sur mobile », « Taille texte mobile (px) », « Ordre sur mobile », « Alignement sur mobile », « Largeur mobile (%) », « Colonnes sur mobile », « Hauteur min. mobile (px) ».

DONNÉES DE LA SECTION
- Fiche affichée par la section : Panneau → Section N → « Données à afficher ».
- Modifier le texte, l'image ou le bouton d'un bloc lié (écrit dans la fiche, partout où elle s'affiche) : double-clic sur le bloc, « ✏️ » dans la Barre du bloc, ou « ✏️ Modifier la donnée » ; fenêtre « Modifier … » (« Version » Français / Anglais, « 🕘 Historique »).
- Présentations d'un groupe : fenêtre « Modifier le groupe de présentations » → « ＋ Ajouter une présentation », « ↑ », « ↓ », « ✎ », « ✕ ».
- Texte propre à la section : « Détacher (contenu propre à la section) », ou dans la fenêtre de la fiche → « Texte propre à cette section ». Relier un bloc : fenêtre « Contenu » → « Relier aux données ».
- Blocs déjà liés à un champ : Section → « 🔗 Blocs liés aux données ».
- Bloc non lié : double-clic, ou « ✏️ Modifier le contenu » ; fenêtre « Contenu » (français et anglais).
- Nombre d'éléments d'une liste : bloc liste → « Nombre d'éléments max ».
- Textes légaux : lien du pied de page vers la page → « Modifier ce texte » → « Enregistrer ».

MÉDIATHÈQUE (dans les fenêtres « Contenu » et « Modifier … »)
- Envoyer : « ⬆ Téléverser une image » / « ⬆ Téléverser une vidéo », ou glisser le fichier sur l'aperçu.
- Choisir un média existant : « 🗂 Médiathèque » ; renommer / supprimer : « ✎ » / « 🗑 » sur le média (suppression refusée tant qu'il sert).
- Vidéo de scène au défilement : cocher « Préparer pour une scène au défilement » avant l'envoi. Retirer du champ : « Retirer ».
- Fond de section : Section → « 📐 Section : dimensions & fond » → « Image de fond (URL) », « Vidéo de fond ».

MODÈLES
- Site entier : Panneau → « 🏛️ Modèles de site » → « Mes modèles » → « 💾 Enregistrer ce site », puis « Appliquer », « ⟳ » (mettre à jour), « ⬇ », « × » ; « Prêts à l'emploi » → « Appliquer » ; « ⬇ Télécharger ce site », « 📂 Charger un fichier » ; « Revenir au site précédent ». Un modèle appliqué ne s'enregistre qu'avec « 💾 Sauvegarder ».
- Une section : Barre de la section → « ✨ Modèles », ou Section → « ✨ Modèles » → « Enregistrer comme modèle ».

HISTORIQUE
- Tout le site (180 jours) : Panneau → « 🕘 Historique du site » → « Afficher », « Détail », « ↺ Restaurer l'état d'avant ».
- Une fiche : fenêtre « Modifier … » → « 🕘 Historique ».
- Mise en page non enregistrée : Section → « ↩ » (Ctrl/⌘ + Z).

RÉGLAGES DU SITE : Panneau → « Paramètres Généraux » → « Navbar (menu du site) », « Footer (pied de page) », « Style/Type de la Page Produit », « Référencement & SEO (Multi-Tenant) » (« Meta Title », « Meta Description », « Mots-clés SEO (séparés par des virgules) », « Image Open Graph (og:image) », « Google Site Verification (Search Console) », « 💾 Sauvegarder le SEO »).

ASSISTANT IA : Section → « 🤖 Assistant IA » (« Retoucher », « Recréer », « 🔍 Relecture visuelle par l'IA ») ; « ✨ Console IA » → « 🧩 Sections » (« Onglet », « Cible ») ou « 🎬 Prompt vidéo ».
