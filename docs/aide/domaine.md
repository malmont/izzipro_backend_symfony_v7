# Domaine propre

Votre site répond déjà sur une adresse de la plateforme. Pour votre propre domaine :

1. Achetez-le chez un registraire (OVH, GoDaddy, Google Domains…).
2. Enregistrez-le dans **Mon site : pilotage**, rubrique Domaine.
3. Créez chez le registraire les **enregistrements DNS** indiqués (A ou CNAME).
4. Attendez la propagation (quelques minutes à quelques heures) et vérifiez : le certificat HTTPS s'émet automatiquement.

L'assistant connaît la procédure et peut enregistrer le domaine pour vous (vous confirmez).
