# Applications

Chaque application se branche sur votre site avec une **clé d'activation** (écran Clés des applications) : générez-la, saisissez-la dans l'application (ou scannez le code QR reçu par courriel).

- **Application e-commerce** : vos clients tapent le **code court** de votre boutique pour la trouver.
- **Application de gestion** : clé d'activation, puis vos comptes administrateurs s'y connectent.
- **Living Memory** : clé portée par l'application pour votre site.

**Apparence** : un profil par application (logo, couleurs, nom, textes) ; sans profil, la fiche Entreprise sert. Un profil est créé automatiquement pour chaque application accordée.
