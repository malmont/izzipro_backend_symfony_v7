Pour l'intégration

        

          Règle des couleurs, identique dans EasyAdmin et dans Flutter
          
    
            
  • Palette : schéma Material « fidelity » calculé depuis la couleur principale (Flutter : ColorScheme.fromSeed(seedColor, dynamicSchemeVariant: DynamicSchemeVariant.fidelity) ; JavaScript : SchemeFidelity de @material/material-color-utilities).
    • 
            
  • Mode clair : la couleur principale du marchand est utilisée telle quelle pour les boutons ; le texte posé dessus est noir ou blanc, celui qui contraste le plus.
    • 
            
  • Mode sombre : la couleur principale est celle du schéma sombre (plus claire), pour rester lisible sur fond sombre.
    • 
            
  • Accent : la couleur d'accent telle quelle, sinon la couleur « tertiary » du schéma ; texte noir ou blanc selon le contraste.
    • 
            
  • Valeurs nulles : couleur principale #ff8900, mode clair, police du téléphone, arrondi 12, boutons pleins, cartes classiques, diaporama.
    • 
            
  • Les valeurs de la palette ci-dessus servent de référence aux tests Flutter du lot L1b.
    • 
          

        

        

          Brancher le formulaire EasyAdmin
          
    
            
  • Le script expose window.ApercuApparence : app (code de l'application) et update(theme, profil) : theme a les neuf clés de app-theme (null = non réglé), profil donne name et logo (adresse de l'image).
    • 
            
  • Chaque champ du formulaire porte data-champ="<clé du thème>" ; un écouteur input relit le formulaire et appelle update. Rien n'est enregistré avant « Sauvegarder ».
    • 
            
  • Un champ non réglé montre la valeur reprise de la charte du site (le même repli que app-theme), pour que l'aperçu corresponde à ce que les clients verront.
    • 
            
  • Un gabarit par code d'application, même contrat pour tous : un fichier apercu-apparence-<code>.html, un conteneur .ap-phone (ou .ap-frame pour une tablette ou un ordinateur), des variables CSS --ap-*, window.ApercuApparence, et un mode intégré : avec ?embed=1 dans l'adresse, seuls l'appareil et ses onglets s'affichent. Celui-ci est mobile.
